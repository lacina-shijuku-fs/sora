# 探求テーマ発見ワークシート（Web版）

`login.html` でログインしてから使う静的サイトです。生徒はスタッフから配られた
名前＋パスワードでログインし、スタッフは共通パスワードでログインします。
回答データは Google スプレッドシートに保存され、Google Apps Script (GAS) を
橋渡し役にして読み書きします（生徒・スタッフともGoogleアカウントへのログインは不要）。

- 生徒：ログイン後の[choose.html](choose.html)で「中学生・高校生向け」「小学生向け」を選び、
  ワークシートに回答 → 提出（スプレッドシートに保存）→ [自分の結果を見る](mypage.html) でいつでも自分の結果だけ確認可能
- スタッフ：[staff.html](staff.html) で全生徒（両方の学年帯）の回答一覧を確認可能

中学生・高校生向け（`index.html`〜`step6.html`、全6ステップ）と、小学生向け
（`elementary/`フォルダ、全4ステップ・質問数も少なめ）の2種類のワークシートがある。
どちらも同じ生徒名簿・同じスプレッドシートの「回答」シートに保存され、「トラック」列
（`中高生` / `小学生`）で区別される。

## 1. スプレッドシートを準備する

先生のGoogleアカウントで新しいスプレッドシートを作成し、シートを3枚用意する。

**「生徒名簿」**（1行目は見出し）

| 名前 | パスワード |
| --- | --- |
| 山田 太郎 | ab12 |

**「回答」**（1行目に以下の見出しをそのまま入力。生徒が提出すると自動で行が追加・更新される）

```
名前 学年 日付 タイムスタンプ トラック ScoreA ScoreB ScoreC ScoreD ScoreE ScoreF
キーワード 深掘りキーワード どこが気になる 自分との接点 もっと知りたいこと
問い1 問い2 問い3 チェックリスト 調べ方 最初の一歩 サマリー
```

「トラック」列には自動で `中高生` または `小学生` が入る（同じ名前でもトラックが
違えば別の行として保存される）。小学生向けは STEP5・STEP6 が無いため、
問い1〜3・チェックリスト・調べ方・最初の一歩は空欄になる。

**「スタッフ設定」**（A1は見出し、A2にスタッフ共通パスワードを入力）

| スタッフパスワード |
| --- |
| staff2024 |

## 2. Apps Script を設置する

1. スプレッドシートのメニュー「拡張機能」→「Apps Script」を開く
2. デフォルトの `Code.gs` の中身を全て削除し、このフォルダの [gas/Code.gs](gas/Code.gs) の内容を貼り付けて保存
3. 右上の「デプロイ」→「新しいデプロイ」
4. 種類の選択で歯車アイコン→「ウェブアプリ」を選ぶ
5. 「実行するユーザー」は **自分**、「アクセスできるユーザー」は **全員** にして「デプロイ」
6. 発行された URL（`.../exec` で終わるもの）をコピーする

※ 学校のGoogle Workspace管理者が外部公開のGASデプロイを制限している場合、
　「全員」でデプロイしても外部からアクセスできないことがあります。その場合は
　管理者に確認するか、Firebase等の代替バックエンドの検討が必要です。

## 3. サイト側にURLを設定する

[app.js](app.js) の先頭付近にある `GAS_API.webAppUrl` に、手順2でコピーしたURLを貼り付ける。

```js
const GAS_API = {
  webAppUrl: "https://script.google.com/macros/s/xxxxxxxx/exec"
};
```

## 4. 公開方法（GitHub Pages）

1. このフォルダ（`tankyu-worksheet`）の中身（`robots.txt`含む）をGitHubリポジトリにpushする
2. リポジトリの Settings → Pages で公開ブランチを指定する
3. 発行されたURL（例：`https://<user>.github.io/<repo>/`）を生徒に共有する

`robots.txt`と各ページの`noindex`メタタグにより、検索エンジンには表示されないようにしてある
（本公開前のテスト運用向け）。ただしURLを知っている人は誰でもアクセスできる点は変わらないので、
本当に外部に見られたくない場合はURLを不用意に共有しないよう注意する。

## 運用メモ

- 生徒の追加・パスワード変更は「生徒名簿」シートを直接編集するだけでよい
- 同じ名前・同じトラックで再提出すると「回答」シートの該当行が上書きされる（行が増え続けない）
- パスワードは平文でスプレッドシートに保存される簡易的な仕組み。学内利用を想定した
  「なりすまし防止程度」のセキュリティであり、外部に公開してよい機密情報の管理には向かない

## 更新履歴（既にセットアップ済みの場合）

小学生向けワークシートを追加した際に、以下の対応が必要：

1. 「回答」シートの見出し行に **トラック** 列を追加する（どこでもよいが、他の見出しと
   同じ行に追加すること）
2. Apps Script エディタを開き、[gas/Code.gs](gas/Code.gs) の最新内容を貼り付け直して
   保存し、既存のデプロイを「デプロイを管理」→編集アイコン→バージョン「新バージョン」で
   更新する（URLは変わらないので `app.js` の再設定は不要）
